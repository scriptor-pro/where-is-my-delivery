Ding-Dong — Politique de confidentialité

Ding-Dong est une extension de navigateur qui surveille une page de suivi de livraison Amazon ouverte dans un onglet, et déclenche une notification locale quand le livreur devient proche.

Données traitées

L'extension lit localement, dans l'onglet actif, le texte affiché par Amazon sur sa carte de suivi de livraison en temps réel (le compteur « N livraisons avant la vôtre »). Cette lecture se fait uniquement sur les domaines Amazon déclarés dans l'extension.

Ce qui n'est jamais fait

  • Aucune donnée n'est transmise à un serveur externe.
  • Aucune donnée n'est partagée avec un tiers.
  • Aucun compte, identifiant ou information personnelle n'est collecté.
  • Aucun suivi publicitaire ni analytique.

Stockage local

L'extension conserve, uniquement sur l'appareil de l'utilisateur (via l'API storage.local du navigateur) :

  • le seuil de notification choisi dans le popup de configuration ;
  • la liste des livraisons déjà notifiées, pour éviter les notifications en double.

Ces données restent locales, ne sont jamais synchronisées ni transmises, et sont supprimées si l'extension est désinstallée.

Permissions demandées

  • storage — pour le stockage local décrit ci-dessus.
  • notifications — pour afficher la notification desktop quand le livreur est proche.
  • Accès aux domaines Amazon (amazon.fr, amazon.com, etc.) — pour lire la page de suivi de livraison ouverte par l'utilisateur.
